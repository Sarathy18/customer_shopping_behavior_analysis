# customer_shopping_behavior_analysis

**Overview**

This project analyzes customer shopping behavior using Python, SQL, and Power BI to uncover insights about purchasing patterns, product preferences, and customer segments. The goal is to transform raw data into meaningful insights and present them through an interactive dashboard and report.

**Dataset**

The dataset contains information related to customer purchases, including:
-Customer ID
-Age
-Gender
-Location
-Product Category
-Purchase Amount
-Payment Method
-Purchase Frequency
The data was used to understand customer trends and support business decision-making.

**Tools & Technologies**

-Python – Data cleaning and Exploratory Data Analysis (EDA)
-Jupyter Notebook – Data analysis environment
-PostgreSQL / MySQL – Database for storing and querying data
-SQL – Data querying and transformation
-Power BI – Interactive dashboard visualization
-Gamma – Presentation creation
-GitHub – Project version control

**Project Workflow**

1. Data Loading
Imported dataset into Python using Pandas
Loaded cleaned data into PostgreSQL/MySQL database

2. Data Cleaning
Handled missing values
Removed duplicates
Corrected data types
Standardized column names

3. Exploratory Data Analysis (EDA)
Performed analysis to identify patterns such as:
Customer age distribution
Purchase trends
Popular product categories
Spending behavior by gender and location
Used Pandas, Matplotlib, and Seaborn for visualization.

4. SQL Analysis
Data was loaded into PostgreSQL/MySQL and analyzed using SQL queries such as:
Total revenue by product category
Top spending customers
Average purchase amount
Customer segmentation queries

5. Power BI Dashboard
An interactive dashboard was created to visualize key metrics:
Key Dashboard Insights
Total Sales
Sales by Category
Customer Demographics
Purchase Trends
Payment Method Analysis

**Results & Insights**

Key findings from the analysis include:
Certain product categories generate the highest revenue.
Customer age groups show different purchasing patterns.
Some payment methods are more commonly used than others.
Regional trends influence shopping behavior
